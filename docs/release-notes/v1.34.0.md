Both versions: C# 1.34.0 and Electron 1.20.0.

- **C#: fast strokes no longer freeze.** After every stroke the history panel threw away and rebuilt all of its rows, and it was not virtualized, so the pause grew with each edit: about 100 ms per stroke after a hundred strokes. Now the panel updates only the rows that changed and creates only the visible ones; the pause stays under 12 ms however long the history gets.
- **Electron and the browser version: Ctrl+P prints only the picture.** It used to print the whole window with menus and panels. Now the page holds a single sheet, exactly as the picture looks on screen, including a selection you are still moving. There is also *File → Print…*.
- C#: 1123 tests (+22), Electron: 469 checks (+10) plus 17 against the real app.

Обе версии: C# 1.34.0, Electron 1.20.0.

- **C#: быстрые мазки больше не подвисают.** После каждого мазка лента истории выбрасывала и заново строила все строки, да ещё и не виртуально - пауза росла с каждой правкой, к сотому мазку около 100 мс. Теперь меняются только изменившиеся строки и создаются только видимые: пауза меньше 12 мс при любой длине ленты.
- **Electron и браузерная версия: Ctrl+P печатает только лист.** Раньше печаталось всё окно с меню и панелями. Теперь на странице один лист - картинка как на экране, вместе с объектом, который ещё в руках. Появился пункт *Файл → Печать…*.
- C#: 1123 теста (+22), Electron: 469 проверок (+10) плюс 17 по настоящему приложению.
