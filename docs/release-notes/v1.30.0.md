C# version only. The Electron version is unchanged.

- **Big photos are about three times faster.** The canvas used to be a bitmap the size of the whole picture; now it is only as big as the window. A 4000×3000 photo while drawing: 28 → 83 updates per second (119 at 25%).
- **Zoom up to 800% on any picture.** A 4000×3000 photo used to stop at 200% because of memory.
- **Ctrl+= at 800% now says it is the limit** instead of doing nothing.
- Layers are drawn without copying: SkiaSharp's `DrawBitmap` copied the whole bitmap on every call.
- 943 tests (+103).
