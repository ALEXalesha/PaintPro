Both versions: C# 1.31.0 and Electron 1.17.0.

- **The mouse wheel resizes the brush in the middle of a stroke.** The new size used to apply only after releasing the button and pressing again. Now the line changes width right away, for the pencil, brush, marker and eraser.
- **Brush and eraser up to 300 px** instead of 100.
- Electron: an eraser stroke resized mid-way was replayed at one size when the history was rebuilt. Each point now keeps its own size.
- Releases now come with a short description of what changed.
- C#: 960 tests (+17), Electron: 390 checks (+14) plus 17 against the real app.

Обе версии: C# 1.31.0, Electron 1.17.0.

- **Колесо мыши меняет размер кисти прямо во время штриха.** Раньше новый размер начинал рисовать только после того, как отпустишь кнопку и нажмёшь снова. Теперь линия меняет толщину сразу - у карандаша, кисти, маркера и ластика.
- **Кисть и ластик до 300 px** вместо 100.
- Electron: ластик, которому поменяли размер посреди штриха, при пересборке истории рисовался одним размером. Теперь размер хранится у каждой точки.
