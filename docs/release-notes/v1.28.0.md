Both versions: C# 1.28.0 and Electron 1.16.0. The two versions now look and work the same.

- **Tools are labelled**, two per row in the left panel, the same icons in both versions.
- **Side panels can be resized** by dragging their inner edge; double click restores the width.
- **The window opens where and how big it was closed**, in both versions.
- **Colour picker window, recent colours and one shared 40-colour palette.**
- Electron: hotkeys work on a Russian keyboard layout. C#: cropping waits for confirmation instead of firing on mouse release.
