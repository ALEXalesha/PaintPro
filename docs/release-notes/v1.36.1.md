Electron version only: 1.21.0. The C# version has no changes; it is numbered 1.36.1 only because releases are tagged by the C# number.

- **Electron: undo works after a flip or a rotation.** After *Flip* or *Rotate* the layer kept the mirror transform. Ctrl+Z put the old picture back mirrored, so it looked as if undo did nothing, and the eraser and the other tools drew on the opposite side. Now the layer forgets the transform right after the flip.
- Electron: 474 checks (+5) plus 17 against the real app. C#: 1144 tests, unchanged.

Только Electron-версия: 1.21.0. В C#-версии изменений нет, номер 1.36.1 у неё только потому, что выпуски идут по номеру C#.

- **Electron: отмена работает после отражения и поворота.** После «Отразить» или «Повернуть» слой помнил зеркальное преобразование. Ctrl+Z возвращал прежнюю картинку зеркально, и казалось, что отмена не сработала, а ластик и другие инструменты рисовали с противоположной стороны. Теперь слой забывает преобразование сразу после отражения.
- Electron: 474 проверки (+5) плюс 17 по настоящему приложению. C#: 1144 теста, без изменений.
