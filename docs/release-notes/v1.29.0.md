C# version only. The Electron version is unchanged.

- **Drawing is about five times faster.** The canvas refreshed 15-18 times a second while drawing: WPF re-blurred every panel shadow on every frame. Shadows are now cached. 900×600 canvas: 17 → 120 updates per second, 1920×1080: 14 → 80.
- **A zoomed-out canvas stays centred at the top**, as in the Electron version. It used to shrink into the top-left corner.
- 840 tests (+132).
