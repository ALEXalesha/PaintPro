Security release for the Electron version. The C# version is unchanged, the number went up because releases are named after it.

- **Electron 33 → 44.4.5.** Version 33 had 32 known engine vulnerabilities, and the engine ships inside the installer and the portable build.
- **electron-builder 25 → 26.15.3.** The old builder pulled in vulnerable packages (build time only). `npm audit`: 21 → 0.

---

Выпуск ради безопасности Electron-версии: Electron 33 → 44 (32 известные уязвимости движка), сборщик electron-builder 26.15.3, `npm audit` 21 → 0. C#-версия не менялась.
