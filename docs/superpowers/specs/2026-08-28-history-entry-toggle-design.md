# Выключатель правки в панели истории

Дата: 2026-08-28. Версия, в которой это выходит: 1.23.0.

## Задача

Сейчас панель истории умеет одно: щелчок по строке приводит документ к этой позиции,
то есть отменяет всё, что сделано после неё. Нужна вторая возможность — **выключить одну
правку из середины ленты, не трогая те, что идут после неё**.

Мысленная модель — выключатель, а не вычёркивание: галочка снимается и ставится обратно
сколько угодно раз, документ каждый раз пересобирается.

## Какие правки выключаются

Деление проходит не по «нарисованное против холста», а по тому, **как правка ложится на
картинку**.

| Запись | Что делает с пикселями | Выключается |
|---|---|---|
| `DrawStrokeCommand` — штрих, фигура, текст | подмешивает свой битмап поверх | да |
| `FillCommand` — заливка | пересчитывается от текущего состояния слоя | да |
| `EraseRegionCommand` — стирание выделения | закрашивает свою форму | да |
| `RegionDiffCommand` — прижатие объекта, вставка | кладёт готовый снимок области | нет |
| `ReplaceAllLayersCommand` — поворот, отражение, кадрирование, открытие | кладёт снимок всех слоёв | нет |
| `ResizeCanvasCommand`, `ClearCanvasCommand`, `LayerStackCommand` | пересобирают стопку слоёв | нет |
| `PasteCommand` | кладёт картинку в руки, пикселей не трогает | нет |

Первые три **складываются** с тем, что уже на слое: пропустить одну из них при проигрывании
можно, и результат будет ровно «как если бы её не делали». Остальные пишут абсолютный
снимок: при пересборке они положат его поверх — вместе с тем, что пользователь выключил, —
и выключатель начал бы врать.

Отсюда правило:

> Галочка есть у записи, которая складывается, и только пока **ниже неё в ленте нет ни
> одной записи, пишущей абсолютный снимок**.

Прижатие поднятого объекта попадает в стоп-список наравне с поворотом. Это строже, чем
кажется на первый взгляд, и намеренно: соврать хуже, чем отказать.

Признак живёт на самой команде (`IDocumentCommand.WritesSnapshot`) и по умолчанию равен
`true`. Новая команда, о которой никто не подумал, автоматически оказывается невыключаемой.

## Как устроено

### Лента

`HistoryManager` держит набор выключенных записей — по ссылке на команду, а не по номеру:
номера едут при обрезке переполнения (`Trim`) и при вычёркивании вставки (`Forget`).

Проигрывание ленты (`Undo`, `Redo`, `JumpTo`) пропускает выключенные записи: курсор через
них проходит, а `Execute`/`Undo` у них не зовётся.

### Переключение

`SetEnabled(command, enabled, doc)` идёт одним путём:

1. запомнить позицию курсора;
2. `JumpTo(0)` — откат обычным способом, по действующим снимкам «до»; они ещё верны;
3. поменять пометку;
4. велеть всем записям от переключённой и ниже забыть снимок «до»;
5. `JumpTo(запомненную позицию)` — проигрывание вперёд с пропуском выключенных.

Шаг 4 обязателен: снимок «до», снятый при первой записи, описывает слой вместе с той
правкой, которую только что выключили. Без пересъёмки первый же Ctrl+Z после переключения
вернул бы пиксели по устаревшему снимку. Пересъёмку умеют делать `DrawStrokeCommand` и
`EraseRegionCommand` (`ForgetBefore`); `FillCommand` пересчитывает себя сам и так.

Записи, которые пишут абсолютный снимок, после пропуска не проигрываются никогда — правило
выше это гарантирует, — поэтому пересъёмка им не нужна.

### Признак несохранённой работы

Метка сохранения запоминает не только позицию курсора, но и набор выключенных записей.
Выключить и включить обратно — значит вернуться к сохранённому состоянию, и вопроса про
сохранение быть не должно.

### Панель

У строки истории появляются два новых свойства: «можно ли выключать» и «включена ли».
Галочка рисуется только у выключаемых; у остальных на её месте пусто, а строка при
наведении объясняет причину. Выключенная строка приглушена.

## Чем защищаемся

К четырём инвариантам фаззера ленты добавляется пятый:

> **Позиция курсора вместе с набором выключенных однозначно задаёт документ.**

Фаззер получает новый вид шага — «переключить случайную выключаемую запись».

Точечные проверки сверх фаззера:

- выключить и включить обратно — документ прежний до пикселя;
- выключение последней записи в ленте равно обычной отмене;
- у записи, ниже которой есть прижатие объекта или правка холста, галочки нет;
- у записи, пишущей снимок, галочки нет никогда;
- переключение делает документ изменённым, обратное переключение — снова сохранённым.

## Чего не делаем

Перестановки правок местами, группового выключения, выключения правок холста и
выключения вставки. YAGNI.
